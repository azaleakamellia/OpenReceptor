# ESG & ESIA Sensitive Receptor Scanner

**Author:** Azalea Kamellia Abdullah, Gs.  
**Domain:** Environmental & Social Impact Assessment (ESIA), TNFD, ADB Compliance, Tropical Remote Sensing  

## 🚀 Project Overview
*(Currently in Active Development)*  
A streamlined, automated geospatial tool designed for environmental consultants to rapidly identify and map "sensitive receptors" within a Project Area of Interest (AOI). 

Traditional ESIA, ESI, and TNFD baseline studies require manual cross-referencing of disparate government databases. This tool bridges that gap by combining **live OpenStreetMap (Overpass API) queries** with **Google Earth Engine (GEE) satellite analytics** to provide an immediate, preliminary sensitivity screening.

## 🛠️ Methodological Framework & Tech Stack
- **Live Receptor Extraction:** Utilizes the Overpass Turbo API to dynamically query OpenStreetMap for protected areas, waterways, critical habitats, and social infrastructure (schools, clinics) within a user-defined buffer.
- **Satellite Baseline Validation:** Integrates with Google Earth Engine (via Python API) to overlay Hansen Global Forest Change or Sentinel-2 imagery, verifying OSM data against actual ground conditions.
- **Compliance Alignment:** Output data structures are designed to map directly to reporting requirements for:
  - **TNFD** (Taskforce on Nature-related Financial Disclosures)
  - **ADB** (Asian Development Bank Safeguard Policy Statement)
  - **ESIA / EIA / SIA** (Environmental & Social Impact Assessments)
  - **ESI** (Environmental Sensitivity Index mapping)

## 💡 Why This Matters for Natural Capital
Accurate, rapid baseline screening is the first critical step in any natural capital or biodiversity assessment. By automating the detection of sensitive receptors, this tool reduces preliminary desk-study time by up to 70%, allowing consultants to focus on high-value field verification and impact mitigation planning.
